# WorkSphere Premium Icon Update

This build keeps the existing WorkSphere HRMS notification/performance code and standardizes the premium WS brand icon across browser, PWA, Apple touch icon, and desktop favicon surfaces.

Included:
- `public/icon.svg` — canonical vector logo
- `public/icon-192.png` — Android/PWA icon
- `public/icon-512.png` — high-resolution PWA/maskable icon
- `public/favicon.ico` — desktop/browser favicon sizes
- `public/favicon.svg` — SVG favicon
- `public/apple-touch-icon.png` — 180x180 Apple home-screen icon
- `public/safari-pinned-tab.svg` — Safari pinned-tab icon
- Updated `index.html`, manifest, and service-worker cache version.
