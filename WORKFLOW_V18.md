# WorkSphere v18 — Workflow & Access Fixes

- Employee Add/Edit department dropdowns now subscribe to the department master in real time.
- Inactive departments are excluded automatically.
- Management can create, edit, publish and delete announcements.
- Employees can only read Published announcements; Draft records are blocked at both query and Firestore rule level.
- Employee announcement UI no longer shows management-only draft status controls or create actions.
- Request, attendance, documents and payroll employee directories continue using role-aware access and realtime employee subscriptions where supported.

Version: 1.0.16
