# WorkSphere v19 — Employee Edit & Premium Salary Slip

- Employee edit now covers the same profile data shown in Employee Details: personal details, employment, address and emergency contact.
- Department remains realtime from the department master.
- New employee creation accepts the same profile fields, keeping Add/Edit symmetric.
- Employee role is intentionally not editable from the employee profile; roles are controlled by the application role system.
- Salary slip PDF includes employee ID, department, designation, salary breakdown, payment details and a stable one-page A4 layout.
- PDF filename format: WorkSphere-Salary-Slip-<Name>-<ID>-Done-<Period>.pdf
- App/PWA version: 1.0.17.
